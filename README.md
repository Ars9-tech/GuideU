# 🚀 GuideU - Smart Campus Navigation System

GuideU is a web-based campus navigation system designed to help students easily locate important facilities such as academic blocks, hostels, libraries, and food outlets within the university campus.

---

## ✨ Features

- 🔐 User Login System (Google Authentication)
- 📊 Interactive Dashboard
- 🗺️ Campus Navigation & Location Info
- 🏫 Academic & Hostel Navigation
- 🍔 Quick Access to Food Outlets

---

## 🛠️ Technologies Used

- 🐍 Python
- 🌐 Flask
- 🧱 HTML
- 🎨 CSS
- ⚡ JavaScript
