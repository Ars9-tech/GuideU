GuideU – Smart Campus Navigation

GuideU is a web-based campus navigation system designed to help students easily locate important facilities such as academic blocks, hostels, libraries, and food outlets within the university campus.
Features
- User login system
- Interactive dashboard
- Campus location information
Technologies Used
- Python
- Flask
- HTML
- CSS
